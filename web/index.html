Features

Everything you need.

A complete notification toolkit for your scripts and automations.

Reply Alerts

Interactive text input directly in the notification. Capture user replies in your script.

Actions & Dropdowns

Add action buttons or dropdown menus. Branch your script logic on user choices.

Custom Icons

Set app icon or attach content images from local files or URLs.

Scheduling

Delay delivery by seconds with --delay or schedule at a specific time with --at.

JSON Output

Get structured output with --json for easy parsing in automation pipelines.

Ignore Do Not Disturb

Critical alerts can bypass Do Not Disturb mode with --ignoreDnd.

Examples

Built for scripting.

Capture user interaction and react to it. Alerter writes the result to stdout - plug it into any workflow.

deploy.sh 
#!/bin/bash
# Ask for deploy confirmation with actions
RESPONSE=$(alerter --title "Deploy" \
  --message "Push v3.2.1 to production?" \
  --actions "Deploy Now,Schedule,Cancel" \
  --sound "default" --timeout 30)

case $RESPONSE in
  "Deploy Now") ./scripts/deploy.sh production ;;
  "Schedule")   ./scripts/deploy.sh --schedule ;;
  "@TIMEOUT")   echo "No response - skipping deploy" ;;
  *)             echo "Deploy cancelled" ;;
esac
backup-monitor.sh 
#!/bin/bash
# Notify on backup completion with JSON output
RESULT=$(alerter --title "Backup Complete" \
  --message "42 files synced (1.3 GB)" \
  --actions "View Log,Open Folder" \
  --json --timeout 10)

# Parse the JSON response
ACTION=$(echo $RESULT | jq -r '.activationValue')

if [ "$ACTION" = "View Log" ]; then
  open ~/backup.log
fi
quick-note.sh 
#!/bin/bash
# Capture a quick note via reply notification
NOTE=$(alerter --title "Quick Note" \
  --message "What's on your mind?" \
  --reply "Type here..." \
  --json | jq -r '.activationValue')

if [ -n "$NOTE" ]; then
  echo "$(date): $NOTE" >> ~/notes.txt
  echo "Saved!"
fi

Alerter is the product of open-source collaboration - shaped by contributors across the world.

Alerter was born in 2012 as a fork of terminal-notifier, created by Julien Blanchard. Over the years it grew into its own project - rewritten in Swift, extended with actions, replies, JSON output, scheduling, and more - thanks to the ideas and code of its contributors.
